Как работает программа

Запуск начинается в main.cpp: создаётся QApplication, открывается база
SQLite и показывается MainWindow. В mainwindow.cpp находятся элементы
интерфейса и обработчики кнопок.

Фигуры отображаются на QGraphicsScene через QGraphicsView. У всех фигур
есть общий абстрактный класс ShapeItem. RectangleItem, EllipseItem
и PolygonItem наследуют его и определяют свой контур в outline().
Общий метод paint() рисует этот контур, заливку и ID фигуры.

При нажатии «Добавить фигуру» параметры из полей собираются в ShapeRecord
и передаются в Database. В SQLite добавляется запись, ей назначается ID.
Затем refresh() перечитывает данные и обновляет сцену и таблицу. ID нужен,
чтобы сопоставлять запись в базе с объектом на сцене независимо от
сортировки строк в таблице.

В базе три таблицы: shapes хранит фигуры, connections — пары ID связанных
фигур, shape_type_stats — количество фигур каждого типа. Связи
неориентированные, повторы и соединение фигуры с самой собой запрещены.
При удалении фигуры её связи удаляются через ON DELETE CASCADE.
Счётчики количества обновляются триггерами SQLite.

ConnectionItem рисует линию между центрами двух фигур. Когда фигура
перемещается, сигнал positionChanged вызывает обновление линии.
После отпускания мыши новые координаты сохраняются в базе. При движении
нескольких фигур изменения записываются одной транзакцией: если возникнет
ошибка, операция откатится целиком.

Для таблицы используется ShapeTableModel, наследник QSqlTableModel.
Он читает SQL-представление shape_overview, где собраны ID, тип, соседи,
количество типа и размеры. QTableView показывает эти данные. Ячейки
не редактируются напрямую — изменения выполняются кнопками.

Фильтры по ID, типу и количеству задают условие через setFilter(), после
чего select() обновляет выборку. Записи при этом не удаляются, а сцена
продолжает показывать все фигуры. Количество относится ко всем фигурам
данного типа в базе, а не только к видимым строкам.

ShapeCountDelegate рисует значки в ячейке количества: один для 1–3,
два для 4–10 и три для количества больше 10. Значения берутся из модели,
SQL-запросы при рисовании не выполняются.

Сборка описана в README.md. Нужны C++17, CMake и Qt с Widgets, SQL
и драйвером SQLite. На разных ОС меняются пути установки Qt, компилятор,
оформление и расположение базы. Windows EXE нельзя использовать вместо
сборки для Linux или macOS. Проверка выполнена на Windows 11,
Qt 6.8.3 и MinGW-w64 13.1; Linux и macOS отдельно не проверялись.

В tests/editor_tests.cpp проверяются сохранение, удаление связей,
фильтры, недопустимые операции, значки количества, перемещение
и действия через интерфейс. Все семь сценариев прошли.
